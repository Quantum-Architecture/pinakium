# Security Policy

## Reporting a vulnerability
Please report security issues privately to **security@quantumexcellium.com**.
Include a description, the affected file or command, and, if possible, a minimal way to reproduce the issue.
We acknowledge reports within 5 working days and aim to publish a fix or a mitigation within 30 days.
Please do not open a public issue for a security report.

## Scope
This repository contains a public, non-enabling verification utility. It is an educational demonstrator:
it is not a legal timestamping service, not a cryptographic library, and not a substitute for a security audit.

## Out of scope
Proprietary Quantum Excellium implementations (QEC, mechanisms covered by our patent applications (filed, not granted), orchestration logic) are not published here and are not covered by this policy.
